## 🔴 NOUVELLE ANOMALIE : Fragments d'URL (#section-X) — 3 000+ impressions gaspillées/mois

**50+ URLs avec fragments (#) apparaissent dans GSC, toutes avec 0 clic.** Le pire cas : l'article `underskoterska-utomlands-2026` avec 8 fragments totalisant ~2 229 impressions/mois à 0 clic :
- `#a1-blankett` : 315 impr

- `#kostnad-och-levnadsstandard` : 328 impr

- `#s-s-ker-du-norsk-auktorisering` : 306 impr
- `#spanien-livskvalitet` : 322 impr
- `#the-golden-opportunity-norge` : 317 impr

**Impact** : Ces fragments diluent le CTR réel des articles (Google les compte comme des URLs séparées). Solution : remplacer les `<a href="#section-X">` par des `<button>` avec `scrollIntoView()` et supprimer les `id` HTML au profit de `data-toc-id` (pattern validé sur solceller24.se — voir `references/fragment-url-fix.md` dans le skill `gsc-audit`).
